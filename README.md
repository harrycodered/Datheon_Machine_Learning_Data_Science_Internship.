# Datheon Machine Learning & Data Science Internship
This repository contains the machine learning pipelines and predictive models built during my Datheon AI Systems & Automation internship.

## Completed Tasks:
* **Task 1: Classification Pipeline** - End-to-end multi-class classification on the Iris dataset using Logistic Regression and Decision Trees.
* **Task 2: Regression Modeling** - Continuous regression modeling and residual error analysis on the California Housing dataset using OLS, Ridge, and Lasso.
* **Task 3: Customer Churn Prediction** - Handled severe class imbalance using SMOTE and trained an ensemble gradient boosting classifier to predict telecom customer attrition.
